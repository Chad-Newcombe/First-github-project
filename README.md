# PawFind Pet Products Directory

A complete, responsive pet products directory built with HTML, CSS, and vanilla JavaScript.

## Pages
- `index.html`: Homepage with hero, category tiles, and trending products.
- `products.html`: Directory grid with filtering and sorting.
- `product-detail.html`: Product detail template with gallery, pros/cons, buy links, and reviews.
- `category.html`: Dedicated pet category page with subcategories and relevant products.

## Features
- Global search with autocomplete suggestions.
- Mobile-responsive header/navigation with hamburger menu.
- Warm pet-friendly visual theme using CSS variables.
- Smooth hover animations and polished card-based layout.
- 20 realistic sample products across Dogs, Cats, Birds, Fish, Small Animals, and Reptiles.

## Run locally
Open `index.html` directly in a browser, or serve via any static server.
